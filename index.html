Firebase Cloud Database & Authentication

Connect your Google Firebase project to enable Firestore cloud database synchronization and technician login across all devices.

Free Firebase Setup Guide (3 minutes):
  1. Go to console.firebase.google.com and create or open your project.
  2. In Project Settings > General, scroll down, click Web (</>) to register an app, and copy the firebaseConfig object.
  3. In Build > Authentication > Sign-in method, enable the Email/Password provider.
  4. In Build > Firestore Database, click Create Database (choose Test Mode or add security rules).
